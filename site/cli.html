  handon           Print triage summary at session start

  plan             Plan operations
  dispatch         Show independent chains ready for parallel agent dispatch (JSON)

  insight          Insight capture and retrieval (append-only JSONL)
  pipeline         Pipeline execution: list, start, advance, and status multi-step pipelines

  pin              Pin the session to a specific repo root path
  unpin            Remove the pinned root from the session
  init             First-time setup: create global config and project state dirs

  scaffold         Generate a test module stub for a crate and testing dimension
