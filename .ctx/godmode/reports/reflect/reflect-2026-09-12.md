### Discovered mid-session

- A broad review can report strong progress while still missing contract-level gaps; the 45/58 and 56/58 audits showed that integration success and resolution completeness are separate checks.
- Restoring unrelated local changes before all final gates are recorded can reintroduce formatting noise even when committed `HEAD` is clean.
- Session evidence must not assume Claude JSONL exists; OpenCode sessions need a git-, report-, and handoff-based fallback.

### Next session speedups

- Freeze and record the integration base before dispatching waves; detect branch movement before each merge rather than during conflict resolution.
- Run the resolution audit after each wave and assign every unresolved row explicitly, avoiding a broad follow-up that still leaves isolated findings.
- Give the full nextest gate more than 120 seconds, and run final gates against committed `HEAD` before restoring preserved local changes.
- Keep local-state restoration as the last step and immediately recheck formatting if source files are restored.
